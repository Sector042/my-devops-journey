mkdir  - makes a new folder
touch  - makes an empty file
cp     - copies a file
mv     - moves or renames a file
rm     - deletes a file (permanent!)
rmdir  - deletes an empty folder
ls     - lists files
ls -l  - lists with details
pwd    - shows where I am
cd     - changes folder
cd ..  - goes up one level
>      - sends output into a file
cat    - prints a file's contents
-a     - to only change access time of a file
-m     - to only change modification time of a file
